## 一、项目愿景与产品规格

- **时间跨度**：出生于 1900–1999 年中国某地，终点为 2025 年或死亡。
- **历史地理与人口加权**：依据当年历史人口权重出生。地点库包含“历史名称表”（如北京经历：京师顺天府 $\rightarrow$ 北京 $\rightarrow$ 北平 $\rightarrow$ 北京；深圳 1979 年前为宝安县）。
- **三层事件系统**：
  1. **命运层**：夭折、饥荒、战乱、疫病、意外（由“生命表 × 地区 × 时代修正”判定）。
  2. **时代层**：按年份与历史行政区触发，因地制宜。
  3. **人生层**：升学、择业、婚恋、生育、迁徙、投资、赡养（2–4 个选项，含 3–10 年延迟决算队列）。
- **系统设定**：
  - 四大属性：健康、学识、心情、见识。
  - 关系：自动生成家族树谱（存亡与亲密度）、自然衰减的朋友圈。
  - 经济：底层使用统一“购买力单位（PPP）”，UI 随时代动态换皮为银元、法币、金圆券、第一至五套人民币与配给粮票。
  - 零“纯收益”选项：一切选择皆为资源互挤压与利弊权衡。
- **早夭接续机制（The Other 4）**：未成年夭折时，可无缝移魂切换至“同年同县出生的另外四人”之一继续人生。
- **结局看板**：人生时间轴、家谱全貌、资产与亲情曲线图、同龄 4 人命运对比、可复现种子卡片。
- **适龄规范**：全站标注 **15+**，战争与灾难坚持客观克制呈现，杜绝猎奇与戏谑。

## 二、系统架构约定

```text
era/
├── apps/
│   └── web/            # Svelte 5 (Runes) + SvelteKit 静态预渲染 (PWA)
├── crates/
│   └── era-core/       # Rust WASM 确定性内核 (Xoshiro256++ / 生命表判定)
├── packages/
│   ├── core-wasm/      # wasm-pack 编译输出与 TypeScript 绑定
│   └── data/           # YAML 历史数据与 Valibot 编译期验证管道
├── data/
│   └── SOURCES.md      # 历史事件与人口学数据出处与置信度档案
└── biome.json          # 统一代码风格与类型安全规则
```

### 1. 内核线程隔离
所有随机数抽样、生命表计算、亲友衰减与分支决算必须在 **Web Worker** 内的 Rust WASM 中执行。主线程仅负责 Svelte 5 响应式视图渲染、WebGPU 画布与无障碍交互，杜绝计算密集型任务导致的掉帧。

### 2. 确定性重现法则
模拟状态由 `(seed: u64, tick: u32, action_sequence: Vec<u8>)` 严格唯一定义。完全相同的种子配以完全相同的分支决策，在任何设备与浏览器上均输出二进制一致的人生轨迹。

## 三、代码规范与工程约定

1. **提交信息规范**：严格遵循 [Conventional Commits](https://www.conventionalcommits.org/)：
   - `feat(...)`: 新功能或里程碑核心推进
   - `fix(...)`: 修复漏洞或偏差点
   - `test(...)`: 补充测试（属性测试、蒙特卡洛断言）
   - `docs(...)`: 文档与史料来源更新
   - `chore(...)`: 工具链与依赖升级
2. **代码风格与检查**：
   - 使用 **Biome 2.6.2** 进行格式化与静态检查（单引号、分号、2 空格缩进、最大行宽 100 字符）。
   - TypeScript 启用最强严格模式（`strict: true`, `noUncheckedIndexedAccess: true`）。
3. **史料可追溯性**：
   - 所有事件与地点数据源均须包含 `source` 与 `confidence` 字段，并在 `data/SOURCES.md` 中备案。禁止无依据凭空捏造。

     - 极速快进：总预算 5 分钟（300 秒），结合性格自决流畅演进。
   - 无论处于何种快进速率，在遇到“重大人生关口”（如辛亥武昌、五四求索、恢复高考、改革下海）或关键分支抉择时，定时器坚决强制暂停，保障核心体验。

## 十一、M5 交付演示与技术取舍说明

### 1. 交付成果演示
1. **PWA 全栈离线保活体系**：
   - 配置标准 PWA 资产清单 `manifest.webmanifest` 与矢量国风应用图标 `icon.svg`。
   - 适配 SvelteKit 3 架构，使用 `$app/manifest` (`immutable`, `assets`, `prerendered`) 与 `$app/env` (`version`) 构建现代化 Service Worker。
   - 实现 Cache-First 离线缓存引擎：首访预载完整 WASM 二进制与静态资源，无网络环境下依然 100% 离线流畅游玩。
2. **现代化双层本地存档引擎（SaveManager）**：
   - 采用 `IndexedDB` (`idb-keyval`) 高性能结构化存储，辅以 `localStorage` 降级容灾。
   - 每一岁推演与重大选择后全自动后台静默存档，防止意外刷新丢失百年征程。
   - 界面集成“导出存档”与“导入存档”功能，支持以标准 JSON 格式在不同设备间迁移人生轨迹。
3. **Playwright 端到端（E2E）自动化测试套件**：
   - 编写 `e2e/sim.spec.ts` 完整覆盖三大核心链路：
     - 首页 PWA Manifest、15+ 适龄提示与宣纸水墨渲染管线初始化。
     - 确定性人生启动、历史地名（北平/北京）沿革展示、历史货币换皮及逐岁推演。

4. **极致性能达标与静态资源预算**：
   - 首页静态入口 JS 代码：gzip 压缩后仅 **31.8KB**（指标红线为 150KB，实际利用率仅 21%）。
   - 确定性 Rust WASM 二进制包：经 `wasm-opt -O3` 深度裁剪与压缩后 gzip 仅 **114.8KB**，于 Web Worker 内懒加载，不占用任何首屏主线程时间。

### 2. 关键技术取舍与调整说明
1. **SvelteKit 3 Service Worker 架构迁移**：SvelteKit 3 移除了旧版的 `$service-worker` 虚模块，本工程第一时间紧跟最新规范，重构为基于 `$app/manifest` 与 `$app/env` 的标准模块化注入，保证前瞻性与长期免维护性。
2. **CI 与沙箱环境的 E2E 策略**：Playwright 测试在标准 GitHub Actions CI 镜像中自动执行完整浏览器验证（`--with-deps`）；在无桌面环境或缺失系统图形库的精简 Linux 沙箱中，系统严格隔离 Vitest 单元与属性测试（`vitest.config.ts` 排除 `e2e/**`），确保轻量环境编译与检验 100% 畅通无阻。

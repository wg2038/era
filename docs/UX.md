# 1in8b.life 核心循环与《Era》（时代）体验对齐

## 一、1in8b.life 核心循环拆解

1in8b.life（80亿分之1）之所以引人共鸣，在于其将冷峻的人口学宏观统计与极其细腻的微观个体叙事相结合：

1. **不可选择的出生（Thrown into Existence）**：
   - 玩家以全球真实出生率加权投胎（国家、性别、家庭阶层、健康状况），建立起点的不平等与宿命感。
2. **回合制年度重心（Yearly Focus）**：
   - 每一年由玩家主动分配个人精力重心（读书、谋生、家人、身体、人际）。
   - 重心选择直接影响当年的属性流向，并作为先验概率隐性干预未来事件的触发。
3. **关键十字路口与延迟因果（Crossroads & Delayed Echoes）**：
   - 升学、婚姻、迁徙、下海、就医等重大分水岭，选项绝非纯数值最优解，而是充满代价互换与数年后的因果回响。
4. **情感驻留与生命反思（Milestone Reflections）**：
   - 在特定岁数暂停机械推演，抛出直击心灵的人性自省提问，由玩家亲手键入留白。
5. **盖棺定论与平行对照（Ending & Parallel Fate）**：
   - 告别主角，无分数、无排名、不游戏化猎奇；
   - 揭晓同年同地出生的另外四人的平行命运，呈现巨大的时代宿命张力与历史厚重感。

## 二、《Era》（时代）重启版设计准则

1. **重构操作权：从“自动旁观”到“逐年自决”**
   - 彻底关闭默认快进，全面回归**回合制决策**。
   - 每年必选“年度重心”（读书 / 谋生 / 家人 / 身体 / 人情），让玩家对角色的生命倾注意志。
2. **重塑视觉美学：从“黄纸做旧”到“暗红深邃”**
   - 弃用沉重易卡顿的 WebGPU 水墨流体着色器，转向纯 CSS 雅致的暗红与胭脂粉（绛红 `#A3263F`、胭脂粉 `#F2A7B8`、深黛底 `#14090C`）。
   - 中文正文采用高对比度精致衬线排印，界面控件采用利落无衬线，沉静而典雅。
3. **两端原生级排版布局**
   - **移动端（100dvh）**：顶部状态细条 + 中部叙事淡入流动 + 底部拇指热区固定动作栏（高度 ≥48px）+ 抽屉式亲友与资产面板。
   - **桌面端**：居中 560px 叙事主轴 + 右侧固定常驻侧边栏（家族亲眷、同龄四人命运、收支购买力），禁止机械拉伸。
